# 0007. 클래스: 상속은 메서드 복사, 메서드 호출은 `OP_INVOKE` 융합

- 상태: 채택
- 날짜: 2026-07-13

## 맥락
`obj.method()`를 속성 조회와 호출로 나누면 호출마다 바운드 메서드 객체를 만든다.

## 결정
- `OP_INHERIT`에서 슈퍼클래스 메서드 테이블을 서브클래스로 복사한다(`tableAddAll`).
- `obj.method(...)`는 `OP_INVOKE`, `super.method(...)`는 `OP_SUPER_INVOKE` 하나로 컴파일한다.

## 대안
- 런타임 슈퍼클래스 체인 탐색: 메서드 조회가 테이블 한 번으로 끝나지 않는다. Lox 클래스는 선언 후 바뀌지 않으므로 복사로 충분하다.
- `OP_GET_PROPERTY` + `OP_CALL`: 호출마다 바운드 메서드 객체를 할당한다.

## 결과
- 장점: 메서드 조회가 테이블 한 번이고, 메서드 호출에 바운드 메서드 할당이 없다.
- 단점/감수한 점: `var m = obj.method;`처럼 호출 없이 꺼내면 여전히 바운드 메서드를 만든다.
