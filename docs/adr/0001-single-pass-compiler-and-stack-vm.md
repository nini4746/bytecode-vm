# 0001. 단일 패스 컴파일러와 스택 기반 VM

- 상태: 채택
- 날짜: 2026-07-13

## 맥락
Crafting Interpreters Part III(Ch 14~29)를 C99로 완주하는 학습 프로젝트다. clox 바이너리는 C 표준 라이브러리 외 의존성이 없어야 한다.
완료 판정은 공식 Lox 테스트 스위트 통과다.

## 결정
- Pratt 파서가 AST 없이 바로 바이트코드를 내보내는 단일 패스 컴파일러(`compiler.c`)를 둔다.
- VM(`vm.c`)은 스택 기반이다. `STACK_MAX`는 `FRAMES_MAX * UINT8_COUNT`다.
- 지역 변수는 컴파일 타임에 슬롯으로 해석하고, 전역만 해시 테이블로 늦게 바인딩한다.

## 대안
- AST 생성 후 코드 생성: 구문 트리 할당이 생긴다.
- 레지스터 기반 VM: 컴파일러가 피연산자 위치를 관리해야 한다.
- 지역 변수 런타임 이름 조회: 지역 접근이 배열 인덱스 하나로 끝나지 않는다.

## 결과
- 장점: 교재 설계 그대로라 단순하고, 코드 생성이 쉽다. 지역 접근이 배열 인덱스 하나다.
- 단점/감수한 점: 전역 접근은 해시 테이블 조회를 거친다.
