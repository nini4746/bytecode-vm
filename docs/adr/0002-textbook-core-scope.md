# 0002. 범위는 교재 본편: 태그드 유니언 Value, 1바이트 상수 인덱스

- 상태: 채택
- 날짜: 2026-07-13

## 맥락
기간은 1~2개월이고 학습 핵심은 본편 Ch 14~29다. Ch 30 최적화는 학습 핵심이 아니다.

## 결정
- Value는 태그드 유니언으로 둔다. NaN boxing과 인라인 캐시(Ch 30)는 하지 않는다.
- 상수 인덱스는 1바이트다. 한 청크에 상수가 256개를 넘으면 `Too many constants in one chunk.` 컴파일 에러를 낸다.
- 라인 번호는 바이트마다 저장한다(`int* lines`).
- macOS clang만 지원한다.

## 대안
- NaN boxing: Ch 30 최적화로 범위 밖이다.
- 긴 상수 opcode 추가: 교재 본편 설계를 따른다.
- 라인 번호 런 길이 압축: 에러 보고에 필요한 정보는 같고, 바이트마다 저장하는 쪽이 단순하다.

## 결과
- 장점: 구현이 교재와 일대일로 대응해 단순하다.
- 단점/감수한 점: 상수 256개 초과 청크는 컴파일하지 못한다. Value 크기와 라인 정보 메모리를 최적화하지 않았다.
